# TmodExtractor
The TmodExtractor program extracts all files from .tmod files, including .cs, .png, audio, and anything else contained within the file.
## Usage
### Basic extraction (output goes next to the .tmod file)
TmodExtractor.exe /path/to/tmod/Mod.tmod

### Extraction with custom output folder
TmodExtractor /path/to/tmod/Mod.tmod /path/to/outputfolder
### Drag and drop
Drag a .tmod file onto TmodExtractor.exe. The output will be created next to the .tmod file.
